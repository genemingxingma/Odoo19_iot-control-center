# 原始加热器的本机首次 OTA 服务

## 当前范围

- 洗脱仪继续使用 USB 刷写。本次不更改洗脱仪固件或生产平台。
- 本机 Wi-Fi 地址：`192.168.20.200`，HTTP 端口：`80`。
- 仅允许 `192.168.20.0/24` 访问，不开放公网、不修改路由器。
- 兼容原始源码请求：`http://iot.huanjibio.com/hj_aiot/heating/target?uuid=<芯片十六进制编号>`。
- 默认仅记录设备请求并返回 `204 No Content`，不会发送固件。
- 初始授权仅准备服务；后续用户已明确授权通过 `06458F` 重启旧加热器做接入检测。
- 重启授权不改变固件下发门槛：当前没有已审核迁移固件，仍不允许下载。

本机验证：109 项 Python 测试通过，其中 13 项覆盖旧 OTA 服务；
PowerShell 启动脚本语法检查通过。服务已在 `192.168.20.200:80` 启动，
健康接口返回 HTTP 200，防火墙地址过滤与上述范围一致。
这些结果不代表真实旧设备已接入，也不代表迁移固件已完成。

## 路由器设置

1. 为本机 Wi-Fi 网卡保留 DHCP 地址 `192.168.20.200`，避免地址变化。
2. 在路由器的本地 DNS 中添加 `iot.huanjibio.com -> 192.168.20.200`。
3. 确保加热器使用该路由器作为 DNS，且可以访问本机；关闭相关访客网络/AP 隔离。
4. 仅修改旧 OTA 域名，不修改 ERP 域名，不做公网端口转发。
5. 路由器改 DNS 不会改变加热器认识的 Wi-Fi SSID 和密码；需让它连接原来认识的 2.4 GHz 网络。
6. 旧程序收到 204 后会继续原有业务，可能加热。当前用户授权的检测采用限时供电和结束后关闭，不进行升级；实际刷写仍需满足下文的负载隔离门槛。

网页检查：`http://192.168.20.200/healthz`。它只证明服务可访问，不证明设备已连接或升级成功。

## 启动和停止

以管理员身份运行项目工具：

```powershell
./tools/start_heater_legacy_ota.ps1 -BindAddress 192.168.20.200
./tools/start_heater_legacy_ota.ps1 -BindAddress 192.168.20.200 -Stop
```

服务为隐藏的临时后台进程，默认 12 小时退出，不设开机启动。
停止命令也会移除本工具创建的防火墙规则。电脑睡眠或离开此 Wi-Fi 会中断服务。
进程退出后窄范围防火墙规则仍需用停止命令清理。

真实设备识别信息和状态只写入外部受限目录：
`D:\Codex\device_backups\heater\legacy-ota-local`。不要提交、共享或打印其中的文件。

## 固件下发前的门槛

只有收到真实旧设备请求后，才可以核对芯片编号、MAC、原固件 MD5、Flash 容量和可用 OTA 空间。
HTTP 请求提供的信息不能证明旧文件系统分区布局，也不能替代硬件接线核对。

普通新版应用 BIN 不能用于这次首次迁移：旧 EEPROM 配置与新版 LittleFS 文件不兼容。
必须准备针对该设备的迁移版本，包含配置迁移、证书/验签公钥和设备注册规划，
默认输出关闭、保持未完成物理验收状态。不可复用另一设备的令牌或公司绑定。
具体迁移固件尚未编写，也尚未在旧设备上验证。

服务仅接受外部受限目录中的 `release.json` 授权包：

- `schema=1`；明确 `heater_load_isolated=true`、`configuration_migration_reviewed=true`。
- `expires_at` 为下一小时内的 UTC Unix 时间戳。
- `chip_id` 为六位大写十六进制编号；`mac` 为小写标准 MAC。
- `source_sketch_md5` 必须与当前请求一致。
- `image` 必须位于受限会话目录内，`image_sha256` 必须与实际 BIN 一致。
- 仅支持已审核的 4 MB 目标；BIN 不超过 1,000,000 字节或设备报告的可用空间。
- BIN 必须含有该设备专用标记 `IMYHEATERMIG1:<chip_id>:4M1M:END`。

标记和人工授权仅用于防止误发普通 BIN，不是独立的安全认证或迁移验证证据。
此旧协议为 HTTP，无法靠服务端补上旧设备不存在的签名验证；仅用于隔离维护网络。
完成首次迁移后恢复路由器 DNS、停止本机服务，后续改用新版签名 HTTPS OTA。
下载完成不等于安装成功，仍需核对设备重启、探头识别、配置和输出关闭。
