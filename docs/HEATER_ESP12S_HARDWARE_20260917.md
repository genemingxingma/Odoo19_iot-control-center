## 三键定义

| 按键 | 原理图网络 / ESP8266 GPIO | 用户指定功能 |
| --- | --- | --- |
| SW1 | IO14 / GPIO14 | 显示芯片序列号和当前 IP 地址 |
| SW2 | IO2 / GPIO2 | 启用或禁用加热功能 |
| SW3 | IO12 / GPIO12 | 显示已接收到的预设温度，不编辑温度 |

R8/R9/R10 分别为 10 kOhm 上拉，三个按键闭合时接地，逻辑按下均为 LOW。

后续实现约束（尚未接入实机固件）：

- SW1 以 ESP8266 芯片 ID 作为芯片序列号，不能与平台的设备 UID、Flash 芯片 ID 混淆；断网明确显示未连接，不显示旧 IP 为当前可达地址。
- SW3 展示设备已经接收并持久化的温度，不显示平台尚未应用的值；没有有效设定时显示未获取，不能把代码中的临时默认温度当作已获取的设定。断网可显示本地保存值。
- SW1/SW3 只切换显示，不改变加热许可、目标值或报警状态。报警在信息页仍需可见，不由信息键清除。
- SW2 关闭加热不等待网络；启用必须具备有效温度、有效设定、正确硬件配置及保护条件。启用是允许本地恒温控制，不是强制连续接通加热器。
- 输入采用非阻塞消抖和单次按下事件；按住不反复切换。复位期间按住的键不能在程序开始后自动触发加热，必须先松开再重新操作。故障复位手势待正确源码核对后确定，恢复读数/网络/电源不会自行恢复加热。
- 不添加本地温度编辑菜单，不把任何 Wi-Fi、公司地址或预设温度硬编码为已配置值。

## 需要先核实的硬件风险

### SW2 与启动状态

GPIO2 是 ESP8266 启动配置引脚。上电、复位及下载时保持 SW2 松开，不以按住 SW2 作为配网或升级入口。启动 ROM 还可能驱动 GPIO2，因此不要在下载模式按下该键。软件消抖不能消除启动采样前的硬件问题。依据：[Espressif Boot Mode Selection](https://docs.espressif.com/projects/esptool/en/latest/esp8266/advanced-topics/boot-mode-selection.html)。

### 原理图 NTC/ADC 分支的条件性风险

图上 ADC 由 R5 上拉至 VCC，NTC 接至 GND；C11/C12 的电容不提供直流分压。按该图推算，NTC 断开时 ADC 节点会趋向 VCC，而不是保持测温时的分压。ESP8266EX 外部 TOUT 输入规定为 0..1.0 V，不能套用带板载分压的 NodeMCU A0 输入范围。依据：[ESP8266EX Datasheet, ADC](https://documentation.espressif.com/0a-esp8266ex_datasheet_en.html)。

这是仅针对图示 NTC/ADC 分支的风险判断，不代表实际 DS18B20 接法存在同一风险，不代表已经量到过压或证明器件已损坏。应先核实实板是否仍有该分支及额外分压/钳位；若存在，由熟悉电路的人确认开路保护，不要带电拔探头制造测试故障。软件检测 ADC 饱和后停热不能替代 ADC 引脚过压保护。

### 加热驱动

此图只到 CN1，不能确定高低有效、继电器/SSR 类型或上电默认关闭能力。不能凭 GPIO16 编号猜测 HIGH/OFF 或 LOW/OFF。首次验证应断开加热负载，保留独立温控/过温断电保护。
